## 🚀 How It Works

### Technical Stack
- **Frontend:** Next.js 14, React, TailwindCSS, Framer Motion
- **Backend:** Next.js API routes with Python integration
- **Astronomical Engine:** Swiss Ephemeris with DE406 ephemeris file (~350MB of precise astronomical data)
- **AI Integration:** OpenAI API for natural language processing and astrological interpretation
- **Blockchain:** Web3 wallet integration with Wagmi/Viem
- **Payments:** Coinbase Commerce integration

### User Flow
1. Enter your birth details (date, location, and approximate time of day)
2. Optionally provide physical traits or other relevant information
3. Our system calculates precise planetary positions using the Swiss Ephemeris
4. AI analyzes the astrological data and your input to determine likely birth time windows
5. Receive a personalized prediction with detailed astrological justification

*Note: Astro Clock is a sophisticated tool that combines traditional astrological techniques with modern technology. Results are for informational purposes and should be verified with other methods when absolute precision is required.*

## 💻 Installation & Deployment

### Prerequisites
- Node.js 18+ (20+ recommended)
- Python 3.8+
- Swiss Ephemeris library (`swisseph` Python package)
- DE406 ephemeris file (~350MB)

### Local Development
```bash
# Clone the repository
git clone https://github.com/yourusername/astro-clock.git
cd astro-clock

# Install dependencies
npm install
pip install -r requirements.txt

# Set up environment variables
cp .env.example .env
# Edit .env with your API keys

# Download the ephemeris file (if not included)
./download-assets.sh

# Start the development server
npm run dev
```

### Production Deployment
Astro Clock can be deployed to various platforms including Render, Vercel, or Netlify. See the [DEPLOYMENT.md](./DEPLOYMENT.md) file for detailed instructions.
